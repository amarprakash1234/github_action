## 📌 About the Project

This is my personal portfolio website, built to present my technical expertise, projects, and professional profile in one place.

The website is hosted using **GitHub Pages**, with **GitHub Actions** used to automate the deployment workflow and streamline updates.

## ⚙️ Deployment Workflow

The portfolio is hosted on GitHub Pages, and GitHub Actions automates deployment.

1. Make changes to the website source code.
2. Commit and push the changes to GitHub.
3. GitHub Actions runs the configured workflow.
4. The updated website is deployed to GitHub Pages.

## 💻 Run Locally

To run this project on your local machine:

```bash
git clone https://github.com/amarprakash1234/github_action.git
cd github_action
```

Open `index.html` in your browser, or use the Live Server extension in VS Code if your project uses a static HTML, CSS, and JavaScript setup.
